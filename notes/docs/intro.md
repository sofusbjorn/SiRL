# Simulation-based Reinforcement Learning Course Notes

Welcome to Simulation-based Reinforcement Learning Course. This course will cover serveral topics related to programming learning-based algorithms for controlling physical systems such as robot arms.
The course strives to blend mathmatical models, algorithm principles and practice on both software and lab works. Given the extensive contents, the course modules are introductory while providing references for in-depth study. Despite of the name, experience or a course record on reinforcement learning, such as [ORel](https://kurser.ku.dk/course/ndak21003u), is not a prerequisite but definitely a welcome. This course will also not specifically delve into the general RL topic, for which one can refer to many [online resources](https://stable-baselines3.readthedocs.io/en/v2.3.2/guide/rl.html). However, one of the expected outcomes is to let students use a Reinforcement Learning perspective to describe a robot control problem, how the problem components are interconnected and what hardware interface and software toolkits can be used to implement and solve the problem.

The course contains following modules:

* __Reinforcement Learning System__: This module will give a general introduction about the motivation, formulation and a taxonomy of algorithms for solving RL-based robotics problems. The note will also talk about commonly used programming practice to transfer a problem into concrete code: _reinforcement learning environment_. A code sample of environment is provided and demonstrating how the task defined by the environment can be learned with an algorithm library.

* __Lab Space and Vision Data__: This module zooms into the state and action space of a reinforcement learning system. The necessity of retrieving state from and applying effects to real world relies on interfacing sensory and electromechanical systems. The note will give a brief introduction to the DIKU physical lab space and summarizes a few links about the rules, tutorials and other resources to use the space. The specific focus is about tracking object state through optical tracking system and programming UR5e robot arms to realize desired movements.

* __Articulated Dynamics__: A computational model linking state and action can create a virtual counterpart of the real world, a.k.a simulation. Solving an RL problem with a virtual model in computers has many benefits. For robot arms, a useful model is to approximately simulate the dynamics of rigid links connected through articulations. This module will go through fundamentals about how to compute the motion of rigid links under input action and articulation constraints. The note will cover the motion description with spatial algebra, motion equation of a rigid link and algorithms to compute inverse and forward kinematics/dynamics of open-chain articulated systems. In the end, the note will also introduce some commonly used robot dynamic simulators.

* __Automatic Differentiation__: Solving RL problems with the addition of simulation models is commonly formulated as numerical optimization. Efficient optimization tends to rely on gradient evaluation through the simulation process. This module touches a software technique for evaluating the derivatives of program output with respect to its input. The note will cover the general principle of representing the program computation as a graph and propagating derivatives over the graph through forward and reverse mode evaluation. This will link to some efficacy and feasibility consideration in writing automatically differentiable code using libraries such as PyTorch and JAX.

* __Optimal Control__: The building blocks of simulation and gradient evaluation pave the way to predicting the robot state under a sequence of actions, and how the actions should be adjusted to improve a quality measure. This module talks about such an basic optimal control problem and its numerical solution via direct shooting. This completes the reinforcement learning diagram for the problem of controlling a robot when the simulation model is available. The note will also talk about its broader usage and reference some software packages that are more centered at general optimal control.

* __Adjoint Method__: As an optimization problem, optimal control has a special structure with simulation as dynamic constraints along a time horizon. Simply differentiating back through the horizon can be hard when the computation process is long, complex or has to rely on code segments not written with autograd libraries. The topic of this module is about how to tackle these issues. The core is to exploit the fact that the simulation equation can implicitly determine state from action and model parameters. Implicit function theorem shows that, the relation between derivatives will allow a direct evaluation of the target derivative without differentiating the explicit process of calculating the state trajectory. The note will give a general description to the reasoning and demonstration on its effectiveness in solving optimal control.

* __Simulation-based Reinforcement Learning__: This module wraps up all pieces together for a general picture of modeling, descrbing and solving robot control under a simulation-based reinforcement learning framework. The capability of efficiently simulating and inverting a robot motion process makes it very flexible to align the simulation to experiment data and hence learn better performing actions for real world. The note shows that it is possible using real data, possibly acquired from the lab space, to calibrate the simulation parameters and again deploy the learned solution to the real system. This will be concluded by a few extra references on general sim2real and real2sim robotics research and practice.
